MSc research · Document AI

Teaching an image to be easier for OCR to read

Tesseract is a black box: useful, but not something you can backpropagate through. For my MSc, I trained a transformer to imitate it closely enough that a modified U-Net could learn which changes to an image would actually help. The oddest part was making the method work on full documents instead of tidy little word crops.

  • 58.5% relative reduction in document word error rate on POS receipts
  • 23.5% relative reduction in document word error rate on SROIE receipts
  • 95.1–98.1% fewer OCR calls per pass through the training data
Read thesis ↗

Approach: modified U-Net preprocessor, TrOCR surrogate, alternating training, group normalization, gradient accumulation, and document-level evaluation.

Scope: results use Tesseract on the thesis’s POS and SROIE splits. The improvements are dataset- and setup-specific, and some large images required resizing or cropping.

The useful bits

  • Turning a paper idea into working code
  • Designing experiments that answer one thing at a time
  • Finding out why a metric moved
  • PyTorch, TrOCR, U-Net and Tesseract

Current work · Autonomous systems

When two perception runs disagree, I want to know why

A slightly better F1 score is not very useful if one run used a different timestamp, frame, class map, or ground truth. I build repeatable comparisons for LiDAR-only and camera–LiDAR perception, then chase down the unglamorous alignment problems before trusting the result.
